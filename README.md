# Search Enhancer for Google™

A browser extension that enables you to enhance Google™ search with infinite scroll, server country icons, \"View Image\" and \"Download Image\" buttons, and more.

## Path to the images download folder in Firefox

Due to Firefox extension API limitations, this setting isn't available in the Firefox version of the extension. 

## Build steps

1. `git clone https://github.com/loftyshaky/search-enhancer-for-google`
2. `cd` into the cloned repository
3. `npm install`
4. `npm run prod_test` (Chrome) / `npm run prod_test_edge` (Edge) / `npm run prod_test_opera` (Opera) / `npm run prod_test_brave` (Brave) / `npm run prod_test_yandex` (Yandex Browser) / `npm run prod_test_firefox` (Firefox)
